# Broadcom System Architecture Academy

中文个人学习网站，静态 HTML / CSS / JavaScript，无构建依赖。公开内容不包含私人笔记或客户配置。

直接打开 `dist/index.html` 可离线使用。建议通过固定 HTTPS 网址学习，以便保持同一个浏览器存储空间。

## 功能

- Module A–E 复习重建版，以及从原聊天整理的 TH5 Lesson 1 / 2。
- 课程、知识点与案例搜索。
- TH5 Clos 端口/容量实验室，单 Spine 故障可视化。
- 原文选区批注、整节批注、定位、编辑、已理解状态和追问复制。
- 每课笔记、学习状态、阅读位置；全部本地保存。
- JSON 备份导出与合并导入。多设备不自动同步。

## 内容边界

非 Broadcom 官方课程。Module A–E 未取回原始全文，明确标为主题复习重建版。1024 GPU、NIC 与拓扑均为教学假设。N-1 示例仅覆盖单台 Spine；没有宣称最少交换机数量或所有流量模式下无阻塞。

批注保存引文与字符偏移；文字改变时尝试按引文重定位，无法定位时保留批注全文。练习不会替换课程正文。

## 维护与托管

`dist/` 可原样部署到 GitHub Pages 或其他静态托管。GitHub Pages 使用分支根目录发布时，把 `dist/` 内四个文件上传到仓库根目录。更新课程内容编辑 `content.js`，界面与交互分别编辑 `styles.css` / `app.js`。

个人数据按网址、浏览器和设备隔离。切换托管网址前先导出备份，再在新网址导入。
