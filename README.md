# Broadcom System Architecture Academy

中文个人学习网站，静态 HTML / CSS / JavaScript，无构建依赖。公开内容不包含私人笔记或客户配置。

直接打开 `dist/index.html` 可离线使用。建议通过固定 HTTPS 网址学习，以便保持同一个浏览器存储空间。

## 功能

- 三阶段学习路径：基础框架 A–E v2、TH5 架构实战、H1–H6 硬件设计进阶计划。旧复习正文与章节链接保留。
- 课程、知识点与案例搜索。
- TH5 Clos 端口/容量实验室，单 Spine 故障可视化。
- 原文选区批注、整节批注、定位、编辑、已理解状态和追问复制。
- 每课笔记、学习状态、阅读位置；全部本地保存。
- JSON 备份导出与合并导入。多设备不自动同步。

## 内容边界

非 Broadcom 官方课程。Module A–E 已新增基础框架 v2 导学，原复习重建版保留在历史资料区；不声称恢复了缺失的原始全文。H1–H6 仅提供计划，详细正文待编写。1024 GPU、NIC 与拓扑均为教学假设。N-1 示例仅覆盖单台 Spine；没有宣称最少交换机数量或所有流量模式下无阻塞。

批注保存引文与字符偏移；文字改变时尝试按引文重定位，无法定位时保留批注全文。练习不会替换课程正文。

## 维护与托管

`dist/` 可原样部署到 GitHub Pages 或其他静态托管。GitHub Pages 使用分支根目录发布时，把 `dist/` 内全部文件上传到仓库根目录。原复习内容保存在 `content.js`；新版基础框架和进阶计划在 `curriculum.js`。更新课程内容时编辑相应文件，界面与交互分别编辑 `styles.css` / `app.js`。

个人数据按网址、浏览器和设备隔离。切换托管网址前先导出备份，再在新网址导入。
